# Exercise 1 — String i anasjelltë (rekursive)

## Detyrë

Shkruani një metodë rekursive `stringAnasjellte(String text)` që kthen një string në të kundërt.

Shembull: `stringAnasjellte("JAVA")` kthen `"AVAJ"`.

Implementoni zgjidhjen rekursive duke:
- hequr karakterin e parë,
- kthyer mbrapsht tekstin e mbetur,
- kombinuar rezultatet.
