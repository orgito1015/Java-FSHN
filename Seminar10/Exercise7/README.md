# Exercise 7 — Flok dëbore Koch (grafikë rekursive)

## Detyrë

Një flok dëbore Koch ndërtohet në mënyrë rekursive sipas këtyre hapave:
- fillimisht krijohet një trekëndësh barabrinjës,
- çdo segment ndahet në tre pjesë të barabarta,
- segmenti i mesëm zëvendësohet me dy segmente që formojnë një trekëndësh të vogël barabrinjës,
- i njëjti proces përsëritet për çdo segment të ri.

Shkruani një program grafik që vizaton iteracionet e kësaj forme në mënyrë rekursive.
Shtoni një buton që, pas klikimit, prodhon iteracionin pasardhës.
