# Exercise 3 — Kontrolli i përmbajtjes së një stringu (rekursive)

## Detyrë

Përdorni rekursionin për të implementuar një metodë që teston nëse një tekst i dhënë përmban një string.

Qasja e kërkuar:
- nëse teksti fillon me stringun që kërkohet, metoda përfundon me sukses,
- përndryshe, kontrollohet teksti pas heqjes së karakterit të parë.
