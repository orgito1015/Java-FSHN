# Seminar 11

## Ushtrimet

- **Exercise1** — Modifikimi i Selection Sort për renditje zbritëse të numrave dhe renditje të lumenjve sipas gjatësisë.
- **Exercise2** — Aplikacion grafik që vizualizon Bubble Sort me shtylla vertikale dhe butonin **Rendit**.
- **Exercise3** — Klasë `Student` që implementon `Comparable` dhe gjetja e studentit të parë/fundit alfabetikisht.
- **Exercise4** — Menaxhim i 1000 kontakteve (emër/telefon), renditje alfabetike dhe kërkim sipas emrit/numrit.
