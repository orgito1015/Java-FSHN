# Exercise 1 — Selection Sort i modifikuar

## Detyrë

Modifikoni algoritmin **Selection Sort** për të renditur:

1. Një array me numra të plotë në rendin zbritës.
2. Një array me informacion për lumenjtë (`emër`, `gjatësi`) në bazë të gjatësisë së tyre.

## Zgjidhja

- `selectionSortZbrites(int[] arr)` rendit numrat nga më i madhi te më i vogli.
- `selectionSortLumenjSipasGjatesise(River[] lumenjte)` rendit objektet `River` sipas gjatësisë në rend zbritës.
