# Exercise 2 — Vizualizimi grafik i renditjes

## Detyrë

Krijoni një aplikacion grafik në Java që vizualizon renditjen e një array-i me vlera numerike:

- çdo vlerë të paraqitet si shtyllë vertikale,
- në klikim të butonit **"Rendit"**, të përdoret algoritmi **Bubble Sort** në rend rritës,
- paneli grafik të përditësohet gjatë renditjes.

## Zgjidhja

Ky ushtrim përdor:

- `JFrame` + `JPanel` për paraqitjen grafike,
- `Timer` për të animuar hapat e Bubble Sort,
- butonin **Rendit** për nisjen e procesit.
