# Java-FSHN

## Purpose

This repository contains Java exercises and examples created as part of coursework at **FSHN** (Faculty of Natural Sciences). It covers introductory and intermediate topics, including static methods, OOP, GUI development with AWT/Swing, collections, inheritance, and algorithms.

## Programming Language

- **Java**

## How to Compile and Run

Use a JDK (Java 8+ recommended), then compile and run from the directory of the exercise you want:

```bash
cd path/to/folder

# Compile all files in that exercise folder
javac *.java

# Run the class that contains main()
java ClassName
```

You can also compile a single file directly:

```bash
javac FileName.java
java ClassName
```

> **Note:** Files using Swing or AWT require a graphical display environment.
