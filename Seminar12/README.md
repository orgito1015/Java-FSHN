# Seminar 12 — Java Collections Framework

## Teori

1. **Collection** është një strukturë që ruan grupe elementësh.  
   **Java Collections Framework** është bashkësia e interface-ve dhe klasave standarde (`List`, `Set`, `Queue`, `Map`, etj.) për menaxhimin e tyre.

2. **Bashkësi (`Set`)** është më e mirë kur:
   - nuk duam dublikatë,
   - na duhet kërkim i shpejtë,
   - rendi i elementeve nuk është kritik.
